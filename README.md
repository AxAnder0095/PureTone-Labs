# PureTone Labs

E-commerce based website for selling a wide range of headphones

## Teck Stack

**Front End**
- React 18 + Vite
- React Router
- Axios for API calls
- Auth0 React SDK

**Backend**
- Node.js + Express
- MongoDB (Atlas)
- JWT verification with Auth0 (`express-jwt + jwks-rsa`)
